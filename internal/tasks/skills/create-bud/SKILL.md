---
name: create-bud
description: Draft a new Bud's name, role, and standing instructions and show a creation card.
---

Use the user's description to draft a Bud with a short name, a clear role, and practical instructions about what it should own, when to ask, and what to report back. Pick a reasonable name if the user gives a role and leaves the name to you. Ask what the Bud should do if the request gives no purpose. Return the profile using the structured bud_proposal action. Buddy creates it when the user selects Create Bud on the card. Describe the proposal as a draft until then.
